# Superstore Sales & Profit Analysis — Data Visualization Project

## Overview

This project analyzes the uploaded `SampleSuperstore.csv` dataset using Python.

The analysis focuses on sales, profit, quantity, discount, category, sub-category, region, state, city, customer segment and shipping mode.

> This specific dataset does not contain order dates, customer names, product names or order IDs. Therefore, the project does not fabricate time-series or customer-level analysis.

## Dataset

File:

`SampleSuperstore.csv`

Place it in the same folder as the notebook:

```text
Superstore Project/
├── SampleSuperstore.csv
└── Superstore_Sales_Profit_Analysis.ipynb
```

## Portfolio Positioning

This is suitable as a **Data Analyst portfolio project** because it demonstrates the complete workflow from raw transactional data to business recommendations.

The strongest part of the project is not the number of charts. It is the ability to connect the charts to measurable business questions such as profitability, discount impact, regional performance and loss-making product categories.
